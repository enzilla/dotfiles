# Pi Global Instructions

- Read the repository's instructions and relevant files before editing.
- Make the smallest correct change; reuse existing code before adding dependencies.
- Preserve unrelated changes in dirty worktrees.
- Never expose, commit, or modify credentials, private keys, tokens, or local session data.
- Ask before irreversible actions, destructive commands, or decisions that require user preference.
- Run the narrowest relevant validation before reporting completion.
- For user-facing React Native or Expo work, load `react-native-ui-flow` before planning or editing; let it infer the phase and load only the relevant child skills.
